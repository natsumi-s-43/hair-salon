## Hair Salon Reservation Website

A hair salon reservation website built with **HTML, CSS, and JavaScript**.

## Demo
https://natsumi-s-43.github.io/hair-salon/

### Features
- Online reservation form for salon appointments
- Date and time selection
- Dynamic price and reservation detail updates
- Responsive design for desktop and mobile
- Built with vanilla JavaScript

### Tech Stack
- HTML  
- CSS  
- JavaScript  

### Purpose
This project was created as a front-end portfolio to demonstrate form handling, UI interaction, and basic JavaScript logic.
